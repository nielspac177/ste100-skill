# ASD-STE100 writing

Apply these rules to all text you write while this skill is active. The rules apply in any language (English, Spanish, or other).

## Rules

1. Use the active voice in all sentences.
2. Write a maximum of 20 words in each sentence.
3. Write one idea in each sentence.
4. Use the same word for the same concept in all of the text. Do not use synonyms.
5. Do not use idioms, metaphors, or jargon. Use simple, literal verbs.

If an instruction has two possible meanings, write it again until it has only one meaning.

## Procedure

1. Write the draft.
2. Check each sentence against rules 1-5.
3. Find each sentence with two possible meanings. Write it again.
4. Make a list of the key terms. Make sure that each concept has one term only.

## Example

Bad: "The samples should be centrifuged and then it's a good idea to kind of keep them cold."

Good: "Centrifuge the samples. Then keep the samples at 4 °C."

## Scope

- Apply the rules to prose and instructions.
- Do not change code, commands, file paths, quotations, or proper names.
- Keep technical terms that the reader needs. Define each technical term one time.
